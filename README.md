# ♔ PC Chess Game

A modern, full-featured web-based Chess application built with Next.js, React, TypeScript, and Stockfish AI.

![Live Demo Banner](https://img.shields.io/badge/Live%20Demo-chess--game--two--sigma.vercel.app-brightgreen?style=for-the-badge&logo=vercel)

🚀 **Live Deployment:** [https://chess-game-two-sigma.vercel.app/](https://chess-game-two-sigma.vercel.app/)

---

## ✨ Features

- ♟️ **Full FIDE Chess Logic:** En passant, castling, promotion, checkmate, stalemate, and FIDE time forfeit rules.
- 🤖 **Stockfish AI Integration:** Play against Stockfish WebAssembly engine directly in the browser via Web Workers.
- 🎨 **Modern Responsive UI:** Glassmorphism dashboard with player cards, captured pieces display, and evaluation bar.
- 🎵 **Sound Effects & Audio Manager:** Immersive audio for move, capture, check, and game end events.
- 📱 **Progressive Web App (PWA):** Installable on mobile and desktop devices.
- 🌗 **Dark Mode & Styling:** Built with Tailwind CSS and Radix UI components.

---

## 🚀 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/Madhuritgithub/Chess-Game.git

# Navigate into project
cd Chess-Game

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15 / React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS, Lucide Icons, Radix UI
- **Engine:** Stockfish WASM Engine
- **Deployment:** Vercel
